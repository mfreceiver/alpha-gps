## 关键决定

- **玻璃**：三级（G1 卡片 / G2 悬浮条 / G3 对话框）+ 预览页专用深色面。真实背景模糊仅 API 31+（Haze）；API 26–30 降级为近实色 + 1dp 描边 + 微渐变。照片网格滚动区不做实时模糊。
- **对话框按钮**：底部左右并排的玻璃胶囊，取消在左（淡色）、确认在右（主色实底，破坏性为红色），各占一半宽；全应用统一。
- **后台常驻语义**：Home、切后台、根页返回、从最近任务划掉都不断开蓝牙；只有 Wi‑Fi 会话结束；蓝牙仅在设备页“断开蓝牙”并确认后断开。
- **预览页**：横竖图同一布局——信息条、胶片条、下载按钮半透明叠在照片底部；信息条默认只有定位图标、锁星、格式·分辨率、大小；拍摄参数、镜头、直方图是设置里的三个开关（默认关），只影响信息条，上滑详情始终完整。窗口形状分三档适配。
- **多存储卡**：两卡合并浏览，仅两卡都有内容时给 2 号卡的照片加“卡 2”小标；容量按卡分行。新目录路径目前只读 1 号卡，属待开发 + 待实机核实。
- **帮助/赞助/关于**：帮助只有设备清单一个入口；移除自动赞助提醒；新增关于页写明上游、修改声明、许可证与两处源码地址。

## mockup 的局限

SVG 无法做真实背景模糊，图中以“渐变背景 + 半透明填充”近似；真实效果以第 4 页 token 为准。相机名、照片、数值均为示意。
