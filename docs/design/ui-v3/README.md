## 关键决定

- **玻璃**：三级（G1 卡片 / G2 悬浮条 / G3 对话框）+ 预览页专用深色面。minSdk 31，恒为真实背景模糊（Haze），不再有降级样式。照片网格滚动区不做实时模糊。
- **对话框按钮**：底部左右并排的玻璃胶囊，取消在左（淡色）、确认在右（主色实底，破坏性为红色），各占一半宽；全应用统一。
- **设备页**：标题为设备名；连接卡 = 状态行（副行为时间校正文案）+ 右侧固定槽位（断开小图标 + 二次确认 / 取消 / 连接）；位置卡只有一张、一行三格（信号 / 已写入 / 最近写入）；底部主按钮“照片传输”，蓝牙未连时先连蓝牙（30 秒超时）。用户主动断开后不自动重连。
- **后台与退出语义**：蓝牙 + GPS 常驻——Home、锁屏、切应用、划卡、根页返回都不断开，仅在设备页主动“断开”并确认后才断蓝牙。Wi‑Fi 照片传输：退后台无下载即结束；有已接受的下载（单张 / 批量）保留到下载结束后自动结束（后台最长 30 分钟）；划卡与根页返回立即结束（即使下载中）。
- **预览页**：文件大小只在底部信息条出现一次，口径 = 按当前下载方式将要下载的大小；定位图标与锁星 tag 在顶栏下方的状态行；拍摄参数、镜头、直方图是设置里的三个开关（默认关），只影响信息条，上滑详情始终完整。窗口形状分三档适配。
- **日期与网格**：日期内不分页，整日一个网格；日期列表无封面缩略图（待办）、不显示固件 / 序列号 / 卡容量。多存储卡设计保留但待实机核实后才落地（M5b，不阻塞其它）。
- **合规**：移除 Sentry；隐私说明全部重写（不收集、不上传任何数据）；关于页写明上游、修改声明、许可证与源码地址（只写 GitHub；私有部署仓库的地址不出现在应用、代码与文档里）；“支持上游作者”链接全应用仅关于页一处。
- **开发拆分**分两条线：W1 文档与素材、W2 代码；都不复制进 `docs/todo.md`。

## mockup 的局限

SVG 无法做真实背景模糊，图中以“渐变背景 + 半透明填充”近似；真实效果以第 5 页 token 为准。相机名、照片、数值均为示意。应用图标直接引用 `docs/brand/alpha-gps-icon.svg`。
