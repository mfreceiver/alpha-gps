- PDF：`docs/design/ui-v3/ui-design-v3.pdf`（27 页，1400×1000 横版，约 6 MB）
- 基线：分支 `feature/browse-only-download`，HEAD `587f510`（v0.1.5）。仅设计交付，未改动应用代码。
- 范围：全应用界面——设备清单、欢迎与配对、设备页、Ⓘ、连接叠层、日期列表、日期网格、视图选项、选择态、单张预览、设置、帮助、日志、通知、空态/错误态；亮/暗两套。

## 关键决定

- **玻璃**：三级（G1 卡片 / G2 悬浮条 / G3 对话框）+ 预览页专用深色面。真实背景模糊仅 API 31+；API 26–30 降级为近实色 + 1dp 描边 + 微渐变，布局不变。照片网格滚动区不做实时模糊。
- **后台常驻语义**：Home、切后台、根页返回、从最近任务划掉都不断开蓝牙，位置写入继续；只有 Wi‑Fi 会话随界面离开而结束；蓝牙仅在设备页点“断开蓝牙”并确认后断开。现有实现里需要改的是三个退出入口（见第 26 页）。
- **连接叠层**：固定尺寸卡片与三个固定高度槽位，各帧只换内容，不跳变。
- **预览页**：横图用上下空白放拍摄参数、定位状态、直方图、文件信息；竖图收敛为压在照片底边的一条玻璃。
- **帮助/赞助**：帮助只有设备清单一个入口；移除所有自动弹出的赞助提醒，仅保留帮助页里的手动链接。

## mockup 的局限

SVG 无法做真实背景模糊，图中以“渐变背景 + 半透明填充”近似；真实效果以第 3 页 token 为准。相机名、照片、数值均为示意。

|---|---|
| `pages3.py` | 入口：生成 mockup → `index.html` → `ui-design-v3.pdf` |
